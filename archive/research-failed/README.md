# 調査不合格の記事アーカイブ

このディレクトリには、一次情報の再確認または構成の見直しが必要なため、公開対象から隔離した過去の記事成果物を保存します。

- `articles/{slug}/` 配下だけが制作・品質チェック・手動コピーの対象です。
- このディレクトリのHTMLは公開用成果物ではなく、WordPressへコピーしてはいけません。
- 再公開する場合は、承認済み構成、対象サービスの提供状況、公式URL、料金、利用条件を再調査し、新しい `articles/{slug}/` として制作工程を最初から実行します。
- アーカイブを検査対象から外すためのメタデータ例外やスキップ指定は設けません。公開対象外であることをディレクトリ境界で明確にします。
