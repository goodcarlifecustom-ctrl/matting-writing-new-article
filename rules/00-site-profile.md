# 00-site-profile: Writingマッチングメディア サイトプロファイル

- サイト名: Writingマッチングメディア
- 既定サイトURL: https://matching.writing-corp.co.jp/
- 対象メディア入力: `target_media` は任意。未指定・空欄時は既定サイトURLを使用し、`なし`・`null`・別URLが指定されても記事生成を停止しない。
- 出力方式: リポジトリ内で記事制作と検証を完結し、`article-decorated.html` を手動コピー用の最終成果物とする。
- 外部処理: WordPress REST API、XML-RPC、管理画面、WP-CLIへの接続・認証・書き込み、およびWordPress以外の記事配信先への書き込みを禁止する。記事調査に必要な公開情報の読み取りと、このリポジトリへの通常のファイル保存・commit・Pull Requestは認める。
- メディアの主題: 出会い系、セフレ、風俗、ナンパ、マッチング等の成人向け情報を、安全・同意・法令順守の観点を含めて解説するSEOメディア。
- 想定読者: 成人読者。出会い・性的関係・夜のお店に関心があり、方法だけでなく危険回避、相手への配慮、料金や規約、身バレ対策を知りたい人。
- 主な記事タイプ: ハウツー、注意点、比較、地域ガイド、サービス解説、FAQ。
- 文章のトーン: 率直でわかりやすいが、扇情的にしすぎず、同意・安全・法令・プライバシーを必ず添える。
- 推奨する記事構成: 結論、この記事でわかること、安全上の前提、具体的な選び方/進め方、リスクと回避策、FAQ、まとめ。
- 主要カテゴリー: セフレ、ナンパ、出会い系、風俗、未分類。
- 内部リンク方針: 同じカテゴリーの記事、サービス解説、地域ガイド、安全対策記事へ自然にリンクする。リンク先の主題を本文で説明する。
- 外部リンク方針: 公的機関、公式サービス、利用規約、法令、相談窓口など一次情報を優先。成人向け店舗情報は公式URLと確認日を残す。
- CVまたは読者に取ってもらいたい行動: 成人読者が安全・合法・同意を前提に自分に合うサービスや行動を判断し、必要に応じて公式情報を確認する。
- 禁止表現: 必ず出会える、確実に関係を持てる、未成年を対象にする表現、同意なしを許容する表現、違法行為を促す表現、相手を侮辱・搾取する表現。
- 根拠確認が必要な情報: 料金、年齢条件、利用規約、法的リスク、店舗所在地、営業時間、届出・許認可、統計、健康・安全情報。
- センシティブなテーマの安全ルール: 年齢確認、双方の明確な同意、個人情報保護、詐欺・勧誘・業者対策、犯罪や危険行為の非助長、健康・法律は専門機関/公式情報の確認を促す。

## 調査メモ

公開トップページでは「セフレ」「ナンパ」「出会い系」「風俗」「未分類」のカテゴリーと、成人向け出会い・風俗関連の新着記事が確認できる。既存記事のトーンは悩みへの共感から入り、方法・注意点・FAQへ展開する形式が多い。新規記事では既存記事の文章や見出しをコピーせず、トピック単位で検索意図を整理して独自構成にする。
